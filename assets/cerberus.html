DIAGRAM 08 FGSM Algorithm — Step-by-Step Visualization
STEP 1
Forward Pass
Input image x [32×32×3]
→ Neural Network (32L conv)
→ Output logits [batch × 10]
→ Cross-entropy loss L(θ, x, y)
STEP 2
Backward Pass — Compute Gradient
∂L/∂x = gradient tensor Shape: [batch × 32×32×3]
Shows which pixels affect
the loss most strongly.
STEP 3
Sign & Scale Perturbation
perturbation = ε · sign(∂L) if ∂L/∂pixel > 0 → Δ = +ε
if ∂L/∂pixel < 0 → Δ = −ε
ε = 8/255 ≈ 3.1% of pixel range
STEP 4
Generate Adversarial Example
x' = clip(x + ε·sign(∂L), 0, 1) Visually: ~imperceptible
Functionally: fools model
Complexity: O(1) gradient
x' = x + ε · sign(∇_x L(x, y))

0.15s

Complexity

DIAGRAM 10 C&W Algorithm — Optimization-Based Attack
SETUP
Change of Variables
x' = tanh(w)/2 + 0.5 Ensures x' ∈ [0,1] automatically
Unconstrained optimization
w₀ = arctanh((2x−1)·0.999)
OBJECTIVE
Loss Function
loss = ||x'−x||₂² + c·CE(model(x'),y) L₂ distance (minimize perturbation)
+ c · classification loss
Adam optimizer (lr = 0.01)
ITERATE
100 Optimization Steps
For t = 0 to 99:
x' = tanh(w)/2 + 0.5 → compute d = ||x'−x||₂²
→ compute L = CE loss
→ Adam step on w
RESULT
Valid Adversarial Example
✓ Valid (in [0,1])
✓ Minimal L₂ perturbation
✓ Causes misclassification
✓ Strongest attack (98%)
