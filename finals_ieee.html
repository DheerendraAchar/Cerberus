02
Attack Execution Pipeline
Step-by-step workflow from user request to result delivery
Flow
Input
{attack, architecture, epsilon, num_samples, dataset}
↓
① Load Model
Cache hit  → use cached model
Cache miss → load from disk
Move to device (CPU/CUDA)
Set eval mode
↓
② Load Data
CIFAR-10 → load_cifar10_loaders()
AG News  → load_ag_news_loaders()
Normalize / tokenize → device
↓
③ Clean Predictions
logits = model(clean_input)
pred   = argmax(logits)
A_c    = sum(pred == labels) / N
↓
④ Instantiate Attack
fgsm    → FSGMAttack(model, eps)
pgd     → PGDAttack(model, 100 iter)
cw      → CWAttack(model, 200 iter)
deepfool→ DeepFoolAttack(50 iter)
jsma    → JSMAAttack(theta=1.0)
⑤ Generate Adversarials
FGSM:     δ = ε·sign(∇_x L)  [1 step]
PGD:      100 iter, project ε-ball
C&W:      200 iter optimization
DeepFool: minimal boundary δ
JSMA:     saliency map pixels
↓
⑥ Clamp to Valid Range
Vision: clamp(x_adv, 0, 1)
Text:   clamp(x_adv, 0, vocab_size)
↓
⑦ Adversarial Predictions
logits_adv = model(x_adv)
pred_adv   = argmax(logits_adv)
A_a        = sum(pred_adv == y) / N
↓
⑧ Compute Metrics
ASR      = 1 - A_a
Δ Acc    = A_c - A_a
‖δ‖      = norm(x_adv - x)
L∞ dist  = max(|x_adv - x|)
↓
⑨ Return JSON Result
clean_accuracy:     92.3
adversarial_accuracy: 68.5
attack_success_rate:  74.2
execution_time_ms:   245
visualization: [base64]
03
Adversarial Training Defense Pipeline
Step-by-step model hardening mechanism with FGSM-based adversarial training
Training
Input: Baseline model θ₀, training dataset D, perturbation budget ε, mix ratio α, epochs E
Output: Hardened model θ* with +10–15% robust accuracy, −2–5% clean accuracy trade-off
Phase 1 — Setup: Initialize θ ← θ₀ · Create Adam optimizer (lr=0.001) · Load training data in batches · Set device
For each epoch, for each batch:
1
Generate Adversarial Examples
x_adv = x_batch + ε · sign(∇L(θ, x_batch, y_batch))
2
Mix Clean & Adversarial
x_mixed = α·x_batch + (1-α)·x_adv where α ∈ [0,1]
3
Forward + Loss + Backward
logits = θ(x_mixed) → L = CrossEntropy(logits, y) → ∇ = ∂L/∂θ
4
Optimizer Step
θ ← θ - η·∇ (gradient descent update)
Epoch-end evaluation — Evaluate at ε' ∈ {0.01, 0.02, 0.03, 0.06, 0.1}
x_adv_test ← FGSM(θ, x_test, y_test, ε') → acc(ε') = accuracy(θ(x_adv_test), y_test)
